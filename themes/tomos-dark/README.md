# Tomos Dark

tomos-darkは、暗い背景で文章を静かに読める、ミニマルなダークテーマです。

## このテーマについて

標準的なTomosのページ構造を保ちながら、配色とコントラストをダーク表示向けにしたテーマです。

## 主な特徴

- 暗い背景と明るい文字色
- 文章を落ち着いて読める配色
- 標準的なページ構造
- JavaScriptに依存しない構成

## テーマ構成

- `templates/layout.html`
- `templates/page.html`
- `templates/list.html`
- `assets/style.css`
- `theme.json`

## テーマ制作について

テーマの作成・カスタマイズについては、[Tomos公式サイト](https://tomoswords.org/)をご確認ください。
