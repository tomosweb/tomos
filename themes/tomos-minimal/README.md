# Tomos Minimal

Tomos標準の最小テーマです。シンプルな構造で、独自テーマの出発点にも向いています。

## このテーマについて

文章とナビゲーションを素直に表示する、余計な機能を持たない軽量テーマです。

## 主な特徴

- 最小限のHTML/CSS構成
- JavaScriptに依存しない表示
- 通常ページと一覧ページに対応
- 標準ロゴ由来の基本アセットを同梱

## テーマ構成

- `templates/layout.html`
- `templates/page.html`
- `templates/list.html`
- `assets/style.css`
- `theme.json`

## テーマ制作について

テーマの作成・カスタマイズについては、[Tomos公式サイト](https://tomoswords.org/)をご確認ください。
