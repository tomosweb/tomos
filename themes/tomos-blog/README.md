# Tomos Blog

tomos-blogは、プロフィールと新着記事を主役にする個人ブログ向けのTomosテーマです。

## このテーマについて

標準テーマの中では、専用のトップページと画像アセットを組み合わせた応用例です。個人ブログのトップページを中心に設計しています。

## 主な特徴

- プロフィール画像とヘッダー画像を使用
- 新着記事を中心にしたトップページ
- 個人ブログ向けのレイアウト
- PC、タブレット、スマートフォンに対応
- JavaScript、外部フォント、外部画像に依存しない構成
