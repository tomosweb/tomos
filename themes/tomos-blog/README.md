# Tomos Blog

`tomos-blog` は、プロフィールと新着記事を主役にする個人ブログ向けの Tomos テーマです。

## 特徴

- トップページに最新12件を表示
- 記事カードに公開日を表示
- PC、タブレット、スマートフォンに対応
- JavaScript、外部フォント、外部画像を使用しない軽量構成
- パンくず、タグ、検索、RSS、フォルダーページングに対応

## プロフィール画像とヘッダー画像の変更

画像はFTPまたはサーバーのファイルマネージャーを使い、`assets/` 内の同名ファイルを差し替えます。テンプレートの編集は不要です。現在の `/post/` 画面にはテーマ画像のアップロード機能はありません。

- `assets/profile.png`: 正方形。512×512pxを推奨します。
- `assets/header.png`: 横長。1920×820px前後を推奨します。

PNG形式のまま、ファイル名を変更せずに上書きしてください。画像変更後はブラウザのスーパーリロードを行います。

画像は最大4時間ブラウザにキャッシュされる場合があります。以前の画像が残る場合は、`templates/home.html`、`templates/layout.html`、`templates/page.html` にある画像URLの `?v=1.1.1` を `?v=1.1.1-2` などの新しい値へすべてそろえて変更し、ブラウザを再読み込みしてください。テーマのレイアウト全体はTomosのHTMLキャッシュ対象外なので、画像URLの識別子を変更すれば公開ページへ直ちに反映されます。

`profile.png` はページ上部、トップのプロフィール欄、記事ページの著者欄で共通使用されます。`header.png` はトップページだけで使用されます。

## 記事一覧とページング

トップページには最新12件だけを表示し、その下にコンテンツフォルダーの記事一覧へのリンクを表示します。

記事一覧ページでは1ページ30件を表示し、31件以上ある場合はページ下部にページ番号と「前へ」「次へ」を表示します。ページングは記事一覧ページで動作し、トップページの最新12件には表示しません。

## 対応バージョン

Tomos `0.1.0-alpha.2` 以降を使用してください。

## インストール

1. `tomos-blog` フォルダーを Tomos の `themes/` に配置します。
2. `/post/` のサイト設定を開きます。
3. テーマ一覧から「Tomos Blog」を選択します。

サイト名、説明文、ナビゲーションは Tomos のサイト設定とコンテンツから反映されます。テーマ内に個人の記事データや外部サービスへの固定リンクは含まれていません。
