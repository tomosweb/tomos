# Tomos Journal

tomos-journalは、日記、エッセイ、個人の記録に向いた、静かで読みやすいTomosテーマです。

## このテーマについて

文章をゆっくり読むことを重視した、余白のある落ち着いたテーマです。

## 主な特徴

- 日記・エッセイなど文章中心の表示
- 読みやすい本文幅と組版
- 静かな配色
- JavaScriptに依存しない構成

## テーマ構成

- `templates/layout.html`
- `templates/page.html`
- `templates/list.html`
- `assets/style.css`
- `theme.json`

## テーマ制作について

テーマの作成・カスタマイズについては、[Tomos公式サイト](https://tomoswords.org/)をご確認ください。
