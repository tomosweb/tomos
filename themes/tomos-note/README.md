# Tomos Note

tomos-noteは、知的記録、研究メモ、読書メモ、技術メモに向いたTomosテーマです。

## このテーマについて

Tomos標準テーマの中で、標準的なテーマ構造を確認するための参照例です。文章を整理して読む用途に向いています。

## 主な特徴

- 明るい紙面と控えめなアクセント
- Markdownの文章を読みやすく表示
- 通常ページと一覧ページに対応
- HTMLテンプレートとCSSを中心にした構成

## テーマ構成

- `templates/layout.html`
- `templates/page.html`
- `templates/list.html`
- `assets/style.css`
- `theme.json`

## テーマ制作について

テーマの作成・カスタマイズについては、[Tomos公式サイト](https://tomoswords.org/)をご確認ください。
