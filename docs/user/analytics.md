# Google Analytics 4の設定

Tomosでは、Google Analytics 4（GA4）の測定IDを任意で設定できます。初期状態では計測しません。

Google Analytics側でプロパティとウェブデータストリームを作成し、`G-`から始まる測定IDを取得してください。初期setup画面で入力できます。setup後はTomos Postの「GA4設定」から変更できます。

測定IDを空欄で保存すると、公開ページにGoogleタグを出力しません。テーマを変更しても設定は維持されます。測定IDをテーマファイルへ直接書き込まないでください。

設定した測定IDは、そのサイト運営者が管理するGoogle Analyticsへアクセス情報を送信するために使用されます。Tomosの運営者や開発者へアクセス情報が送信されるものではありません。

GA4の利用に伴うプライバシーポリシーの表示、Cookieや同意取得、各国・地域の法令への対応は、サイト運営者の責任で確認してください。TomosにCookie同意管理機能は含まれません。

設定後は、GA4のリアルタイムレポートまたはGoogle Tag Assistantで計測を確認してください。広告ブロッカー等により送信が防がれる場合でも、Tomos本体の表示には影響しません。
