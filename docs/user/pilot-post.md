# Tomos Post 先行利用ガイド

Tomosは初期リリース段階です。不具合が発生する可能性があるため、先行利用では次の条件を確認してください。

- 公開内容の責任は利用者にあります。
- 未発表原稿、取材メモ、個人情報、情報源、社外秘情報の保存場所として使用しないでください。
- 公開後に取り下げても、検索エンジンや外部キャッシュに残る場合があります。
- 元のMarkdownと画像は、利用者自身の端末にも保存してください。
- 感想や改善意見をお願いしますが、紹介記事や取材記事の執筆を求めるものではありません。

## 基本ページの更新

1. Tomos Postの「投稿」を開きます。
2. 管理用合言葉を入力し、`index.md` または `about.md` をダウンロードします。
3. [Tomos Write](https://tomoswords.org/write/) または任意のエディタで編集します。
4. ファイル名を変更せず、必要な画像と一緒に上の投稿フォームから再投稿します。
5. 上書き確認後、公開ページと再ダウンロードした最新版を確認します。

`index.md` と `about.md` は取り下げや完全削除の対象外です。画像を変更しない場合は、既存画像を再度選択する必要はありません。

## 管理者が準備するもの

- 利用開始前の初期バックアップ
- `content/`、画像ディレクトリ、`config.php`、Post認証設定の定期バックアップ
- 復元手順と利用終了時のデータ返却手順
- `content/`、画像、説明文を含むデータ返却Zip
