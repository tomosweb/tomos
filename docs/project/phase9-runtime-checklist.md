## 画像なしMarkdown

1. `phase9-no-image.md` を新規投稿し、本文、公開URL、一覧を確認する。
2. 同じファイル名で本文を変更し、上書き後に旧本文が残らないことを確認する。
3. ページを取り下げ、無関係なMarkdownと画像が残ることを確認する。
4. 各操作後に `cache/post-upload-sessions/` へ不要なデータが残らず、画像参照索引に不要な記録が追加されないことを確認する。

## 失敗後の再投稿

1. 10MB超過画像または対応外画像を含め、投稿が公開確定されないことを確認する。
2. 正常な画像へ選び直し、同じMarkdownを再投稿する。
3. 画像送信中に別ページへ移動し、戻ってから同じMarkdownを再投稿する。
4. 旧ページ、一時データ、ロック、再投稿結果を確認する。
