# テーマ

テーマは、Tomosの見た目を決めるファイル一式です。

## setup時に選ぶ

初回setupでは、`themes/` フォルダにある有効なテーマだけを選択できます。

同梱テーマ:

- `tomos-minimal`
- `tomos-journal`
- `tomos-dark`

## 設置後に切り替える

設置後のテーマ切り替えは、Tomos Post内で行います。

1. `/post/` を開く
2. サイト設定の「テーマを切り替える」へ進む
3. 管理用合言葉を入力する
4. 利用できるテーマから選ぶ
5. 確認画面で変更する

テーマ変更後は、TomosがHTMLキャッシュを削除します。公開ページを開き、見た目が切り替わっているか確認してください。

## できないこと

Tomos Postでは、テーマのアップロード、編集、CSS編集はできません。

テーマを追加する場合は、FTPまたはサーバーのファイルマネージャで `themes/` 配下にテーマディレクトリを置きます。
