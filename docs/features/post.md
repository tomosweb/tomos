# Tomos Post

Tomos Postは、Tomos Writeなどで作成したMarkdownファイルをTomosに投稿するための画面です。

Tomos Postでは、共通の管理用合言葉で次の操作を行います。

- Markdownファイルを投稿する
- 現在公開中の `index.md` と `about.md` をダウンロードする
- 投稿済みページを取り下げる
- `trash/` を整理する
- テーマを切り替える
- サイト名、サイト説明、タイムゾーンを変更する
- RSSとSitemapの公開設定を変更する

## 投稿できるファイル

- `.md`
- `.markdown`
- `.txt`

`.markdown` と `.txt` は、Tomos内では `.md` として保存されます。

Markdown内にTomos Write形式の画像指定がある場合は、元画像を選んで一緒に投稿できます。

画像は最大5点、1点10MBまでです。公開操作は1回ですが、画像は内部で1点ずつ順番に送信し、全画像の送信成功後にMarkdownを公開します。JPEG、PNG、WebPはサーバー側で長辺2048px以内へ調整します。保存時の設定はJPEG品質82、WebP品質82、PNG圧縮6です。GIFはアニメーション維持のため元のまま保存します。

10MBの上限は加工前の元画像に適用します。公開先の1回の受信上限がそれより小さい場合は、実行環境から取得した上限に合わせて画像を複数チャンクへ分割します。

順次送信では、開始APIがPHPの `upload_max_filesize` と `post_max_size`、Tomos独自上限から安全余裕を引いた実効上限を返します。元画像が実効上限より大きい場合はブラウザで複数チャンクへ分割し、公開先の一時領域で元画像へ復元します。投稿セッションはPHPセッションと紐づけ、24時間後に自動削除します。各チャンクは最大1回自動再送し、全点が揃うまで公開領域へ保存しません。

上限判定は特定のサーバー事業者や固定の受信容量に依存しません。Webサーバー、プロキシ、WAFなどPHPから把握できない制限で失敗した場合は原因を断定せず、Markdownを公開しないままエラーを返します。利用者へPHP設定の変更を必須とする案内は行いません。画像を一括送信する旧方式へのフォールバックも行いません。

Markdownに必要な画像が不足している場合は、不足している画像を追加で選ぶか、その画像の掲載をやめるかを画像ごとに選べます。掲載をやめた画像の記述は投稿用Markdownからだけ外し、端末に保存されている元のMarkdownは変更しません。

Web上でのMarkdown本文編集、ファイル一覧管理、履歴管理はできません。

## サイト設定

Tomos Postへログインし、「サイト設定」（`/post/settings/`）を開くと、次の項目を変更できます。

- サイト名
- サイト説明
- タイムゾーン
- RSSの有効・無効
- RSS対象パス
- Sitemapの有効・無効

RSS対象パスを空欄にすると、下書きを除くすべての公開ページがRSSの対象になります。設定を保存すると、次の公開画面表示から反映されます。

サイト設定画面には、[Google Analytics 4の設定](analytics.md)と[テーマ変更](themes.md)の各専用画面へのリンクもあります。GA4測定IDと使用テーマは、それぞれの専用画面で変更します。

## トップページとAboutページの更新

Tomos Postの「投稿」に、現在公開中の `index.md` と `about.md` をダウンロードする機能があります。ダウンロードには管理用合言葉が必要で、対象以外のファイル名やパスは指定できません。

1. 現在のMarkdownをダウンロードする
2. [Tomos Write](https://tomoswords.org/write/) または任意のエディタで編集する
3. ファイル名を変更せず、通常の投稿フォームから再投稿する
4. 確認画面で上書き更新を選び、公開ページを確認する

`index.md` と `about.md` は必ず `content/` 直下に保存されます。保存先フォルダを入力しても使用されません。この2ファイルは別名投稿、取り下げ、完全削除の対象外です。

既存の画像参照は、Markdownだけを再投稿しても変更されません。画像を追加または差し替えるときだけ、Markdownと一緒に元画像を選択します。画像上限、形式、リサイズ、失敗時の取り消しは通常記事と同じです。

## 管理用合言葉

管理用合言葉はsetup完了時に一度だけ表示されます。

あとから画面では確認できません。忘れた場合は、`post-reset.enable` を使って新しい合言葉を再発行します。
