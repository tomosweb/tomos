# Tomos v1.0.3 hotfix candidate

この文書は、Tomos v1.0.2で確認されたTheme asset cacheとfavicon fallbackの実環境不具合に対する修正候補です。正式Releaseではありません。

## Included scope

- Themeのlayoutが`theme.asset_version`を使ってstylesheet URLを生成し、Theme versionの更新をcache keyへ反映します。
- Theme固有faviconがない場合は、Core配下の`assets/tomos-default-favicon.png`を使用します。このファイルはTomos公式サイトの丸型faviconと同一byteで、SHA-256は`c7dbba96fce934594db75c5ba61be482cb21649b35464d6f340090f6338d5186`です。
- 固有faviconを持つ既存Themeと、サイト固有のTheme assetは上書きしません。

## Compatibility

- v1.0.2からv1.0.3への署名付きTomos Updateを想定します。
- `config.php`、`content/`、uploads、サイト固有Theme、cache/storage/trashの運用データは更新対象に含めません。
- 本候補ではtag、GitHub Release、production catalog、production deployを行いません。
