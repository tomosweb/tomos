# Tomos v0.7.3

Tomos v0.7.3は、Tomos Write連携の互換性を改善するHotfix Releaseです。

## Fixed / Compatibility

- 一部の設置環境で、公開済み原稿からTomos Writeへ移動できない問題を修正しました。
- 公開済み原稿をTomos Writeで編集し、Tomos Postへ戻す既存の流れを維持します。

## Release transition

v0.7.2からv0.7.3へ、署名付きTomos Updateで更新できます。更新元の`VERSION`が`0.7.2`の環境へ、`from_version: 0.7.2`、`version: 0.7.3`のUpdate ZIPを1回適用します。

`config.php`、`content/`、uploads、サイト固有Theme、運用データはCore Updateの更新対象に含めません。

## Release acceptance

正式公開前に、実際に生成したDistribution ZIPとv0.7.2からv0.7.3へのUpdate ZIPを展開・検証します。公開後は、公開URLから取得したartifactのhash、署名、manifest、VERSION、Installer、Browser Update経路を再検証します。
