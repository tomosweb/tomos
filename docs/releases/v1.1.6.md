# Tomos v1.1.6

## Summary

Tomos Postの「サイト設定」から、Faviconとサイト共通OGP画像を変更できるようになりました。

## Changes

- サイト固有の画像は `theme-assets/` に保存され、Themeを変更・更新しても維持されます。
- 「Themeの画像に戻す」でサイト固有画像を解除できます。
- 記事のFront Matter `image:`、サイト共通OGP、ThemeのOGPの順で画像を適用します。
- サイト固有Favicon、ThemeのFavicon、Core既定Faviconの順でFaviconを適用します。
- PNG / JPEG / WebPに対応し、1ファイル10MBまで登録できます。

## Compatibility / Update

- v1.1.5からv1.1.6への署名付きBrowser Updateで反映します。
- `config.php`、`content/`、`theme-assets/`、custom Themeなどの運用データを保持します。
- Updateでは `theme-assets/` を上書きしません。

## Verification

- Core Regression、Browser Update、PHP 7.4 / 8.0 / 8.2 / 8.5互換性、InstallerのFormal Release Gateを実施後に記録します。
