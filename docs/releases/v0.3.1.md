# Tomos v0.3.1

v0.3.1は、v0.3.0の新規インストール直後に一部サーバー環境で発生するTomos Post管理画面の認証引き継ぎ不具合を修正する緊急パッチリリースです。

## 修正内容

- 新規ブラウザなどRemember認証Cookieがまだない状態で、Tomos Postの「テーマ」「サイト設定」を開いた際に投稿画面へ戻されることがある問題を修正しました。
- PHP session cookieのPathをTomos Post配下へ明示し、サブディレクトリ設置でも認証状態を `/post/theme/` と `/post/site-settings.php` へ引き継げるようにしました。
- サイト設定の正式な入口を `/post/site-settings.php` に整理し、以前の `/post/settings/` は互換用のリダイレクトとして残しました。
- `/theme-labo` 相当のサブディレクトリ設置を使うHTTP回帰テストを追加しました。

## v0.3.0からの更新

通常のTomos Updateでv0.3.0からv0.3.1へ更新します。`config.php`、`content/`、サイト固有テーマ、運用データは更新対象に含めません。

## 互換性

- Markdown仕様は変更しません。
- URL構造は変更しません。
- v0.3.0のTheme Platform契約は変更しません。
- Phase 6以降の未リリースTheme Platform機能は含みません。
