# Tomos v0.3.0

## 概要

Tomos v0.3.0は、Minimal Multilingual Foundationを導入する新機能releaseです。翻訳本文を生成するのではなく、ページの言語情報を正しく保持して公開します。Tomosは0.x開発系列であり、1.0の安定版ではありません。

## Site language

`config.php` の `site.language` はサイトの既定言語です。既定値は `ja` で、SetupとTomos Postのサイト設定から変更できます。

```php
'site' => [
    'language' => 'ja',
]
```

## Page language

Markdownのfrontmatterに `language` を指定できます。

```yaml
---
title: About
language: en
---
```

`language` を指定しないページは `site.language` を継承します。言語タグはBCP 47形式に沿って検証されます。

## Theme contract

coreはeffective languageを `page.language` としてTheme contextへ渡します。標準テーマは次を使用します。

```html
<html lang="{{ page.language }}">
```

標準6テーマを1.3.0世代へ更新しました。

## Multilingual site

同じサイト内に異なる言語のMarkdownページを置けます。

```text
/about/        ja
/en/about/     en
```

URLにlanguage prefixは強制されません。言語はfrontmatterとsite設定を正本とします。公開pageは言語に関係なくSitemapへ収録されます。RSSはsite-level languageを維持します。

## Compatibility

- migrationは必要ありません。
- 既存Markdownの変更は必要ありません。
- 既存URLは変更されません。
- 既定言語 `ja` は維持されます。

## Non-goals

- 翻訳生成
- 翻訳API
- 翻訳関係・翻訳キーの管理
- hreflang自動生成
- language switch自動生成

## Update

```text
product: Tomos
from_version: 0.2.0
version: 0.3.0
```

v0.2.0からv0.3.0へは、通常のTomos Updateで直接更新します。`from_version`は現在の `VERSION` と完全一致する必要があります。
