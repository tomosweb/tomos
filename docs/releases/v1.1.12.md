# Tomos v1.1.12

## 概要

Tomos Postのパスキー認証と管理画面のセキュリティを強化します。

## セキュリティと操作の改善

- パスキー専用モードと、合言葉・パスキー併用モードを選択できます。
- ログイン方法変更時はパスキーで再認証し、セキュリティ画面へ戻って保存します。
- 管理用合言葉の変更・再設定では、生成、表示、コピー、保存案内を利用できます。
- 認証方法・合言葉変更後、古いセッションと30日間記憶認証を失効させます。
- パスキー専用モードでは合言葉による直接ログインを禁止し、最後のパスキー削除を防止します。
- 設定画面の先頭にTomos Update・セキュリティを配置し、Obsidianトークン設定を「連携」へ移します。
- Tomos Write、Bluesky、Obsidianの従来の連携経路を維持します。

## Compatibility / Update

- **v1.1.11からv1.1.12** への署名付きTomos Updateは正式リリース工程で作成・検証します。
- パスキーを利用するにはPHP 8.0以上、HTTPS、WebAuthn対応ブラウザ等が必要です。PHP 7.4では通常の合言葉認証を維持します。
- `config.php`、`content/`、画像、利用者追加Theme、cache/storage/trash、および各種認証データを保持します。
- 本文は**正式公開前の候補**です。マージだけでUpdate配信、Release、公式サイト公開は行いません。
