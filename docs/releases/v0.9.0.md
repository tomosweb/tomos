# Tomos v0.9.0

Tomos v0.9.0は、既存runtimeの整理と安定化を行うpre-releaseです。新機能は追加しません。Theme Developer Previewの状態は変更しません。

## Cleanup / Stabilization

- Browser Updateで保護対象の`.htaccess`を段階的に反映し、既存の`cache/`、`storage/`、`trash/`のデータを保持する経路を整理しました。
- 更新後の必須runtimeファイルを確認し、古いWebAuthn test runtimeを更新対象のlive環境から除去する処理を安定化しました。
- 既存のTomos Post、Tomos Update、Passkey、サブディレクトリ設置の互換経路を維持します。

## Release transition

v0.7.3からv0.9.0へ、署名付きTomos Updateで更新できます。更新元の`VERSION`が`0.7.3`の環境へ、`from_version: 0.7.3`、`version: 0.9.0`のUpdate ZIPを適用してください。Tomos Updateの後にTomos Postを開き、「更新を完了する」を選んでください。

`config.php`、`content/`、uploads、サイト固有Theme、`cache/`、`storage/`、`trash/`の既存データはCore Updateの更新対象に含めません。

## Release acceptance

正式公開前に、実際に生成したDistribution ZIPとv0.7.3からv0.9.0への署名付きUpdate ZIPを検証します。最終Human Release Gateでは、v0.7.3実環境からのBrowser Update、Tomos Postからの更新完了、migration、site startup、および既存データ保持を確認します。正式Release、public repository、update catalogの切替は、この確認後の別工程です。
