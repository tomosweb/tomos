# Tomos v1.1.1

## Summary

Bluesky投稿のハッシュタグ、Obsidian本文からの公開、PHP 7.4互換性を改善しました。Bluesky OAuthの公開MetadataとJWKSは、既存URLを変えずに静的JSONで応答できるようになりました。

## Changes

- `#Tomos` や `#個人サイト` をBlueskyのAT Protocol tag facetとして投稿します。日本語タグ、UTF-8 byte offset、末尾句読点の除外に対応します。
- Obsidian本文のinline tagを外部公開用に正規化し、Inbox経由・自動公開でも一貫した本文を公開します。
- Bluesky OAuth Metadata/JWKSのstatic backing生成コマンドと、既存サイトのmanaged OAuth blockだけを更新する安全な`.htaccess` migrationを追加しました。
- PHP 7.4で`mixed`実型宣言を使用しないようにし、Inbox自動公開を含む対象経路を実行できます。

## Bluesky OAuth static backing

static backingは自動生成しません。Tomosの設置先で、既存のBluesky OAuth鍵を設定済みであることを確認してから、次を実行します。

```text
php tools/generate-bluesky-oauth-static-backing.php --root=/path/to/tomos
```

既存サイトの`.htaccess`は丸ごと上書きせず、次を実行してmanaged blockだけを安全に更新します。

```text
php tools/migrate-bluesky-oauth-static-backing.php --root=/path/to/tomos
```

バックアップ作成、atomic write、rollbackを行えない場合や、managed blockが想定外の構造である場合はmigrationは変更しません。static JSONがない場合は、従来の`.json.php` PHP endpointが応答します。

## Compatibility / Update

- v1.0.8からv1.1.1へのBrowser Updateを対象とし、設定、記事、画像、追加Themeなどの運用データを保護します。
- static JWKSには公開鍵だけを書き出します。秘密鍵、token、session情報はstatic JSONに含めません。
