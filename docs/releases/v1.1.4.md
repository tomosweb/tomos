# Tomos v1.1.4

## Summary

記事画像とBlueskyのOGP画像の処理を見直し、共有ホスティング環境で画像付き投稿を安定して利用できるようにしました。

## Changes

- Tomos Postで長辺2,048pxを超えるJPEG・PNG・WebPをブラウザー側で縮小してから送信します。
- 画像の縮小後は実データから管理画像名を生成し、Markdown内の画像参照も合わせて更新します。
- 記事画像とBlueskyサムネイルで画像処理のメモリ推定を共通化し、処理結果を保護ログへ記録します。
- Bluesky用画像は元画像10MBまでを受け付け、投稿用サムネイルを2MB以下へ縮小・再圧縮します。

## Compatibility / Update

- Tomosの画像アップロード上限は従来どおり1ファイル10MBです。2MB制限はBlueskyへ添付するサムネイルだけに適用します。
- v1.1.3からv1.1.4へのBrowser Updateでは、設定、記事、画像、追加Themeなどの運用データを保護します。
- OAuth、Blueskyアカウント形式、投稿本文・ハッシュタグの仕様は変更しません。

## Verification

- さくらTESTで、約3.4MBの画像を使った記事画像付き投稿とBluesky OGP画像付き投稿を確認しました。
- GitHub Actionsの画像処理PHP・JavaScriptチェックは成功しました。
