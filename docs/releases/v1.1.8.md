# Tomos v1.1.8

## Summary

Tomos Writeで書いた新規Markdown原稿を、Tomos Postの投稿画面へ直接渡せるようになりました。

## Changes

- Tomos Writeの「Tomos Postで投稿」から、Markdown本文とファイル名をTomos Postへ直接handoffします。
- Tomos WriteとTomos Postが別originでも、opener・origin・source・session・transactionを検証して連携します。
- 認証が必要な場合も、Tomos Postでログインしたあと同じhandoff sessionへ戻って原稿を受け取れます。
- Markdown本文をURLへ含めず、新規投稿handoffと既存記事編集handoffを明確に分離します。
- 新規投稿では編集用の`tomos_source_*`情報を除去し、既存記事更新として誤判定しないようにします。
- Tomos Writeから受け取ったことをTomos Postの投稿画面上部に表示します。
- Markdownは1MiBまでに制限し、受信後の最終公開はTomos Post上で人間が実行します。

## Compatibility / Update

- v1.1.7からv1.1.8への署名付きBrowser Updateで反映します。
- `config.php`、記事、画像、サイト固有Themeなどの運用データを保持します。
