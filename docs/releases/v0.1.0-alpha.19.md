# Tomos v0.1.0-alpha.19

## 概要

v0.1.0-alpha.19は、v0.1.0-alpha.18で導入した公式オンライン更新経路を実環境で検証・開始するための最小リリースです。

Tomos本体の機能追加は行わず、alpha.18からのruntime差分はVERSIONのみです。

## アップデート

v0.1.0-alpha.18以降では、Tomos Post → Tomos Updateから公式の次バージョンを確認し、ブラウザ上で更新内容を確認して更新できます。

alpha.18 → alpha.19は、新しい通常Update形式を使用する最初の更新です。

manifestは次の内容です。

```text
product: Tomos
from_version: 0.1.0-alpha.18
version: 0.1.0-alpha.19
```

`minimum_version`は使用しません。

更新は1バージョンずつ行い、自動適用・多段自動更新は行いません。

## 手動更新

従来どおり署名済みUpdate ZIPを使った手動更新も正式な更新経路として維持します。

オンライン更新と手動更新の双方で、同じ署名検証、`from_version`検証、適用処理を使用します。

## 補足

alpha.17 → alpha.18で必要だった`/post/update-finalize/`によるUpdater本体反映は、alpha.18 → alpha.19の通常更新では不要です。
