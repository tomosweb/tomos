# Tomos v0.7.0

Tomos v0.7.0は、外部リンクのカード・公式Embed表示と、外部URL取得の安全性を強化するFeature Releaseです。

## Added

- Amazon URLを単独行で記述するとAmazonリンクカードを表示します。
- Amazonの商品情報取得に失敗した場合は、タイトルとURLを使った汎用カードへfallbackします。
- 通常のAmazon URL、`amzn.asia`、`link.amazon`を扱い、記事に記述した元URLを保持します。
- Apple Musicのsong、album、playlistを公式Embedで表示します。
- Spotifyのtrack、album、artist、playlist、episodeを公式Embedで表示します。

## Fixed / Security

- 外部サービスが障害している場合は、通常リンクへ安全にfallbackします。
- 外部URLのcacheとHTTP取得に上限・公開先検証を適用し、CSPで公式Embedのframe先を許可します。
- description自動生成を修正しました。
- 同梱する6つの公式Themeで外部リンク表示に対応しました。
- YouTubeの既存Embed機能は維持しています。

## Compatibility

- API keyやcredentialの設定は必要ありません。
- v0.6.8からv0.7.0への署名付きTomos Updateを正式経路とします。
- `config.php`、`content/`、uploads、サイト固有Theme、運用データはCore Updateの更新対象に含めません。

## Release transition

更新元の`VERSION`が`0.6.8`の環境へ、`from_version: 0.6.8`、`version: 0.7.0`のUpdate ZIPを1回適用します。更新後はVERSION、外部リンク表示、YouTube表示、保護データ、cache/runtime directoryを確認してください。

## Release acceptance

正式公開前に、開発treeではなく実際に生成したfull distribution ZIPとUpdate ZIPを展開・適用して、PHP lint、runtime parity、外部リンクAcceptance、Installer Phase 1〜5、Update rollback、CSP、不要ファイル混入なしを確認します。公開Repo、tag、GitHub Release、production反映は、これらのartifact gate完了後に別工程として実施します。
