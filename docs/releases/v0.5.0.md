# Tomos v0.5.0

> v0.5.0ではInstaller配布経路の検証に軽微な不整合が確認されたため、v0.5.1への更新を推奨します。Tomos本体の通常利用には影響ありません。

v0.5.0は、Markdown本文からYouTube動画を簡単に表示できるようにした機能追加リリースです。

## 主な変更

- YouTubeのURLをMarkdown本文に単独の1行で書くと、公開ページで動画プレイヤーとして表示できます。
- `youtube.com/watch?v=`、`youtu.be/`、`youtube.com/shorts/`に対応しています。
- query stringやfragmentが付いたURLも、動画IDだけを使って埋め込みます。
- Markdown正本は通常のURLのまま保持します。
- MarkdownリンクにしたURLは、動画ではなく通常のリンクとして表示します。
- 同梱6テーマで本文幅100%、16:9のレスポンシブ表示に対応しました。

## v0.4.0からの更新

通常のTomos Updateでv0.4.0からv0.5.0へ更新します。Update ZIPの`from_version`は`0.4.0`、`version`は`0.5.0`です。`config.php`、`content/`、サイト固有Theme、運用データは更新対象に含めません。

## 互換性

- YouTube URL以外のMarkdown処理は従来どおりです。
- コードブロック、blockquote、list、table内のURLは自動埋め込みしません。
- 生HTMLの標準仕様や、Markdown本文から任意JavaScriptを実行させない方針は変更していません。

## 配布

正式な配布物、Browser Update、InstallerはGitHub Releaseおよび公式配布ページから取得できます。
