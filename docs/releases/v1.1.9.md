# Tomos v1.1.9

## Summary

Tomos Postの画面構成と情報設計を見直し、管理画面全体の視認性と操作の分かりやすさを改善しました。投稿や各連携機能の仕様を変更するリリースではありません。

## UI improvements

- 投稿・下書き・公開済み・設定画面を整理しました。
- NavigationとGoogle Analyticsの設定を独立画面にしました。
- Theme、Bluesky、Security、Passkey、Tomos UpdateおよびUpdate関連画面のUIを共通化しました。
- ローカルSVGアイコン、文字コントラスト、スマートフォンを含むレスポンシブ表示を改善しました。

## Compatibility / Update

- v1.1.8からv1.1.9へ、署名付きTomos Updateで更新します。
- 更新時も`config.php`、`content/`、uploads、サイト固有Theme、cache/storage/trashの運用データを保持します。
