# Tomos v0.7.2

Tomos v0.7.2は、v0.7.1で追加したTomos Post認証境界のサブディレクトリ設置不具合を修正するEmergency Maintenance Releaseです。

## Fixed / Security

- サブディレクトリ設置環境でTomos Postへ管理用合言葉でログインした際、認証後にリダイレクトループする不具合を修正しました。
- Tomos Postの共通認証境界をApacheのRewrite/Referer推測からPHPへ移し、`post/index.php`が認証境界を所有する構造へ変更しました。
- `post/auth-gate.php`は`post/index.php`から一方向に呼び出される認証componentとし、`post/.htaccess`の認証用Rewriteを廃止しました。
- `post/.htaccess`はBrowser Update互換のためコメントのみのtombstoneとして残します。

## Compatibility

- Post API、保護preview/download、Passkey、Settings、Theme、Security、Updateの既存経路を維持します。
- 公開済み記事からTomos Writeを開き、対象Markdownを渡し、編集後にTomos Postへ戻すhandoffを維持します。
- Sakura Apacheのサブディレクトリ実機で、合言葉ログイン、PublishedからTomos Writeへの遷移、対象原稿の受け渡し、編集後のTomos Postへの返送を確認しました。
- v0.7.1からv0.7.2への署名付きTomos Updateを正式経路とします。
- `config.php`、`content/`、uploads、サイト固有Theme、運用データはCore Updateの更新対象に含めません。

## Release transition

更新元の`VERSION`が`0.7.1`の環境へ、`from_version: 0.7.1`、`version: 0.7.2`のUpdate ZIPを1回適用します。更新後はVERSION、Tomos Postログイン、Published/Drafts、Passkey、Tomos Write往復、Post API、保護preview/download、設定・Theme・Security・Updateの各経路を確認してください。

## Release acceptance

正式公開前に、実際に生成したfull distribution ZIPとv0.7.1からv0.7.2へのUpdate ZIPを展開・適用して、PHP lint、runtime parity、認証境界、Tomos Write handoff、Passkey互換、Installer Phase 1〜5、Update rollback、不要ファイル混入なしを確認します。公開Repo、tag、GitHub Release、公式サイト反映はartifact gate完了後に実施します。
