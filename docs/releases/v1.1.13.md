# Tomos v1.1.13

## 概要

Tomos Writeからの記事公開時、Blueskyの自動投稿文に画像の代替文字列（例：IMG6383）が混入する問題を修正します。

## 修正内容

- 自動生成する概要文からMarkdown画像のalt文字列を除外します。
- 冒頭の画像と本文の間に空行があっても、本文を概要文に使用します。
- 明示的なdescription、social_textと、見出しから生成するタイトルの従来の動作を維持します。
- 記事一覧・SEOにも共通の概要文生成を使用し、古い概要文のキャッシュを再生成します。
- 記事原稿、画像のalt属性、画像添付、Bluesky認証は変更しません。

## Compatibility / Update

- 正式公開済みの **v1.1.12からv1.1.13** への署名付きTomos Updateを準備します。
- `config.php`、`content/`、画像、利用者追加Theme、cache/storage/trash、認証データを保持します。派生キャッシュは必要に応じて再生成します。
- 本修正の反映先はTomos Coreです。Tomos Writeのデプロイでは反映されません。
- Obsidian独自画像記法などへの対応拡張は含めません。
- 本文は正式公開前の候補です。マージだけでReleaseや更新配信を公開しません。
