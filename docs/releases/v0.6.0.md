# Tomos v0.6.0

v0.6.0は、Markdownから公開HTMLまでの互換性と、公開Web文書としての基礎metadataを整える機能リリースです。

## Markdown Compatibility 1.0

- nested listの階層を保持します。
- task listを閲覧用checkboxとして表示します。
- `~~text~~`を`<del>`として表示します。
- bold italicのHTML nestingを正規化します。
- fenced codeのlanguage情報を保持します。
- HTTP/HTTPSのbare URLとautolinkをリンク化します。
- Tomos Write PreviewとCore公開HTMLの主要な意味・構造を整合させました。
- `[[page]]`、alias、heading reference、画像形式の`![[image.jpg]]`をTomos Extensionとして扱います。
- standalone HTTPS YouTube URLを専用embedとして扱います。
- raw HTML、script、style、SVG、任意iframeは標準設定で実行・適用しません。

Tomos Markdown 1.0はCommonMark、GFM、Obsidianの完全互換ではありません。正式な対応範囲は[Markdown Compatibility 1.0](../features/markdown-compatibility.md)と共通fixtureで定義します。

## SEO Foundation 1.0

- Coreでtitle、description、canonical URL、page type、site name、social imageを正規化します。
- canonicalと`og:url`を同じ公開URL規則で出力します。
- 記事の`og:type`を`article`、Home・固定ページ・virtual folderを`website`として出力します。
- `og:site_name`、OGP、Twitter Cardを出力します。
- Front Matterの`image`を安全なsocial image候補として扱います。
- sitemapのdraft除外と`lastmod`のmetadata優先を整理しました。
- `/robots.txt`の基本応答を提供します。
- RSS 2.0のURL生成を公開URL規則へ整合させます。
- Themeは`{{{ page.seo_head_html }}}`を`<head>`へ配置するTheme Contractを利用します。

JSON-LD、Atom、keyword meta、SEO score、automatic alt生成、redirect managerなどは含みません。

## Theme

- 同梱6ThemeをSEO head contractへ移行しました。
- 実運用の`tomos-official`と`tomos-blog`を移行しました。
- placeholderがない旧custom Themeはwarning付きで従来互換されます。

## Compatibility

既存記事では、nested list、task list、`~~...~~`、bare URL、language fenced code、raw HTML Previewの表示が変わる可能性があります。既存記事のURLやFront Matterを一律に変更するmigrationはありません。統合回帰では重大な既存記事破壊は確認されていません。

## 更新経路

- v0.5.3からv0.6.0へ、通常の署名付きTomos Updateで更新します。Update ZIPの`from_version`は`0.5.3`、`version`は`0.6.0`です。
- それ以前のバージョンは、従来どおり対応する経由バージョンを順に適用してください。
- `config.php`、`content/`、サイト固有Theme、運用データはCore Updateの更新対象に含めません。
