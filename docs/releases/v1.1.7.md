# Tomos v1.1.7

## Summary

Blueskyのリンクカードへ記事のOGP画像が添付されない場合がある問題を修正しました。

## Changes

- 元OGP画像の取得上限10MBと、Blueskyへ添付する縮小画像の上限2MB以下を分けて扱います。
- 画像取得時に添付画像用の上限を誤適用して、カード画像の処理が止まる問題を修正しました。
- Tomos本体のBluesky投稿処理を修正し、Tomos Workspace経由の投稿にも適用します。

## Compatibility / Update

- v1.1.6からv1.1.7への署名付きBrowser Updateで反映します。
- `config.php`、記事、画像、サイト固有Themeなどの運用データを保持します。
