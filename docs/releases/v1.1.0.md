# Tomos v1.1.0

## Summary

記事を探して読み、別の記事へ移動するための汎用Core機能を追加しました。Wiki・百科事典型Themeを含む、Theme開発者向けの構造化Contextを提供します。

## Changes

- MarkdownのH2〜H4見出しへ安全で一意なHTML `id` を付与します。
- 見出しから記事内目次を生成し、`page.toc`としてThemeへ渡します。
- サイト全体のタグ名・URL・公開記事数を`tag.items`として提供します。
- 公開中の全ページ一覧`/all/`と、Theme向けURL Context `nav.all_url`を追加します。
- 本文中で明示的にリンクされた公開内部ページを`page.related_items`として提供します。

## Theme developer API

次のContextをThemeから利用できます。

- `page.toc`
- `tag.items`
- `nav.all_url`
- `page.related_items`

既存ThemeはこれらのContextを使用しない限り、表示変更なしで動作します。

## Compatibility / Update

- 標準Theme、Tomos Quiet、Tomos Indexとの既存互換性を維持します。
- v1.0.8からv1.1.0へのBrowser Updateを対象とし、設定、記事、画像、追加Themeなどの運用データを保護します。
- Wiki Theme 1.0.0はTomos本体とは別の追加配布Themeとして提供予定です。
