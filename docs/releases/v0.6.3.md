# Tomos v0.6.3

Tomos v0.6.3では、ブラウザからの更新経路の信頼性と、テーマ関連基盤の互換性を改善しました。

## 更新内容

- v0.6.1またはv0.6.2からv0.6.3へ更新できるよう、更新経路を整理しました。
- 同一バージョンを対象とする緊急更新を通常のバージョンアップと分離しました。
- テーマ検証に必要なCore基盤とセキュリティ処理を引き続き整合させました。

v0.6.1からv0.6.3へ、またはv0.6.2からv0.6.3へ、署名付きTomos Updateで更新できます。`config.php`、`content/`、uploads、サイト固有Theme、運用データは更新対象に含まれません。

Theme Developer Centerの公式サイトproduction公開は、今回のReleaseには含みません。
