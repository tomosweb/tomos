# Tomos v0.4.0

v0.4.0は、Theme Platform v1の拡張、Navigation Settings v1、同一テーマIDの安全なTheme ZIP更新をまとめた正式リリースです。

## 主な変更

- Navigation Settings v1のauto/manual切替、manual順序、label上書き、hidden設定。
- Tomos PostのNavigation Settings UI v1。
- same-versionおよびhigher-versionの同一テーマID更新。
- downgrade拒否、active theme選択の保持、directory単位の置換、削除済みファイルのcleanup、失敗時rollback。
- `theme-settings.php`、`theme-assets/`、`content/`、`config.php`を保護するTheme更新境界。
- `tomos-lab`商用ThemeとPhase 6 / Gate 6検証。
- v0.3.1で導入したサブディレクトリ設置時のTomos Post認証引き継ぎ改善の継承。

## v0.3.1からの更新

通常のTomos Updateでv0.3.1からv0.4.0へ更新します。Update ZIPの`from_version`は`0.3.1`、`version`は`0.4.0`です。`config.php`、`content/`、サイト固有Theme、運用データは更新対象に含めません。

## 互換性

- Markdown、既存URL構造、既存Theme設定の責務境界を維持します。
- Theme ZIP更新で保護されるサイト固有ファイルは上書きしません。
- Issue #90およびIssue #95のOPEN PR変更はv0.4.0の対象外です。

## 配布

正式な配布物、Browser Update、InstallerはGitHub Releaseおよび公式配布ページから取得できます。
