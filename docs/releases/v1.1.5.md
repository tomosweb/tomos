# Tomos v1.1.5

## Summary

Tomos WorkspaceからInbox APIへ接続するための本番CORS設定を修正します。

## Changes

- 公式Workspace（`https://tomoswords.org`）からのInbox API preflightを許可します。
- 既存サイトに古いOrigin許可リストが設定されている場合も、公式Workspace Originを利用できます。
- その他のOrigin設定とTomos Publisher token認証は従来どおりです。

## Compatibility / Update

- v1.1.4からv1.1.5への署名付きBrowser Updateで反映します。
- `config.php`、記事、画像、サイト固有Themeなどの運用データを保持します。
- Tomos Workspace側でサイトごとの設定変更は不要です。

## Verification

- Core Regression、Browser Update、PHP互換性、InstallerのRelease Gateを実施後に記録します。
