# Tomos v1.1.14

## 概要

Tomos Write・Tomos Workspace・Tomos Publisherで共通利用するトークンの呼称を、Tomos Postで「投稿用トークン」に統一します。

## 変更内容

- Tomos Postの「設定 → 連携 → Obsidian」を「設定 → 連携 → 投稿用トークン」に改めます。
- 投稿用トークンの発行画面・発行後メッセージを共通トークン向けに整理します。
- 再発行時は3ツールで登録済みのトークンも変更が必要であることを明示します。

## Compatibility / Update

- 正式公開済みの **v1.1.13からv1.1.14** への署名付きTomos Updateを準備します。
- 現在利用中のトークンを再発行・失効させません。既存利用者によるトークンの再設定は不要です。
- トークンの値、認証方式、発行・再発行処理、`/post/obsidian/`、`/post/inbox/api/`、Bluesky連携は変更しません。
- `config.php`、`content/`、画像、利用者追加Theme、cache/storage/trash、認証データを保持します。
- 本文は正式公開前の候補です。マージだけでReleaseや更新配信は公開されません。
