# Tomos v0.6.1

Tomos v0.6.1は、v0.6.0で追加したSEO FoundationのURL処理を改善するpatch releaseです。

## 修正

- 日本語を含むURLのcanonical、OGP、sitemap、RSSが正しい公開URLを使用するようにしました。
- すでにpercent-encodedされたURLが二重encodeされないようにしました。
- 404ページではcanonicalと`og:url`を出力しないようにしました。
- mbstringがない環境でも、日本語のdescriptionをUTF-8の途中で壊さずに扱えるようにしました。

## 更新

v0.6.0からv0.6.1へは、通常のTomos Updateで更新できます。`config.php`、`content/`、custom Theme、サイト固有データは更新対象に含まれません。
