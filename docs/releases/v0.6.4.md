# Tomos v0.6.4

Tomos v0.6.4では、公開済み記事を外部のTomos Writeで編集し、既存のTomos Post更新フローへ戻せるbrowser-to-browser handoffを追加しました。

## New

- 公開済み記事の一覧から「Tomos Writeで編集」を利用できます。
- 編集用Markdownをブラウザ間handoffでTomos Writeへ渡せます。
- Tomos Writeの「Tomosで更新する」からTomos Postへ戻り、既存の更新確認・画像追加・更新を利用できます。
- 編集途中の内容をブラウザのlocalStorageへ保持します。
- Mac Chrome、Mac Safari、iPhone Safariでテキスト編集、画像追加、Tomosへの返送、更新を確認しました。

## Compatibility / behavior

- 従来の「Markdownを取得」とMarkdown upload更新は継続して利用できます。
- 既存画像は保持され、新しい画像は既存のTomos Post画像追加フローで処理されます。
- Tomos本体にeditorを内蔵しません。
- 記事本文はtomoswords.orgのサーバーへ送信・保存しません。
- v0.6.3からv0.6.4へ、署名付きTomos Updateで更新できます。`config.php`、`content/`、uploads、サイト固有Theme、運用データはCore Updateの更新対象に含まれません。

## Fixed

- distribution ZIPの内容検査で、`set -euo pipefail`下の`printf | grep -q`によるSIGPIPE誤失敗を修正しました。ZIP内容の判定条件や許可・拒否ルールは変更していません。
