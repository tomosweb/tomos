# Tomos v1.0.0

Tomos v1.0.0は、凍結済みv1.0 scopeに基づく最初の正式版です。

## Included scope

- v0.9.0で確立したprotected-state guard、fixed-allowlist Browser Update migration/finalize/rollback、SHA-256検証、WebAuthn `_test/` cleanup、Distribution境界を引き継ぎます。
- Daily Use UX、Withdraw context retention、auth `required` / `focus-visible`、assistive status / alert semantics、Reduced Motionを含みます。
- Tomos Message card、Klee One、original Tomos mark、accepted session lifecycle、Human-reviewed final corpus 125文を含みます。

## Update from v0.9.0

v0.9.0からv1.0.0へ、署名付きTomos Updateで更新できます。通常の更新では、v0.9.0で確立したpending/finalize/rollback契約を維持します。

`config.php`、`content/`、uploads、カスタムTheme、cache/storage/trashの運用データはUpdateの更新対象に含めません。

本書はTomos v1.0.0の正式Release案内です。
