# Tomos v0.5.1

v0.5.1は、v0.5.0のYouTube埋め込み機能を維持しながら、Installerの配布経路を修正したメンテナンスリリースです。

## 主な変更

- Installerのpointer検証を、公式mirrorの正規URLである`/installer/releases/<VERSION>/`に合わせました。
- v0.5.0で確認されたInstaller配布経路の不整合を修正しました。
- YouTube URLの単独行埋め込み、Markdown正本の保持、同梱6テーマの16:9表示はv0.5.0から継続します。

## 更新経路

- v0.5.0からv0.5.1へ、Tomos Updateで更新できます。
- v0.4.0からは、v0.5.0へ更新したあと、続けてv0.5.1へ更新します。

`config.php`、`content/`、サイト固有Theme、運用データは更新対象に含めません。
