# Tomos v1.1.10

## Summary

Tomos Postの画像選択と、Tomos Writeから受け取った画像付きMarkdownの投稿を改善しました。

## Fixed / Improved

- 各画像・OGPの「この画像を選ぶ」から、ファイル名や写真データが変わった元画像を指定できます。
- 追加で選択した画像を保持し、画像選択をDataTransferに依存しない形に変更しました。
- `![写真](<IMG_6286.jpeg>)`形式を認識し、選択した画像の公開用パスへ書き換えます。
- 選択済み画像の表示と、照合できない場合の案内を修正しました。
- iPhone SafariでTomos Writeから画像付き原稿を送り、公開記事の画像表示まで実機確認済みです。

## Compatibility / Update

- v1.1.9からv1.1.10へ、署名付きTomos Updateで更新します。
- `config.php`、`content/`、uploads、サイト固有Theme、cache/storage/trashを保持します。
- Tomos Writeから画像ファイルは自動送信されません。Tomos Postで元画像を選ぶ手順は引き続き必要です。
- 修正前に画像が表示されない状態で公開した記事は、元のMarkdownと写真を再投稿して更新してください。
