# Tomos v0.6.2

Tomos v0.6.2では、テーマ関連基盤とアップデート処理の安定性を改善しました。

特にv0.6.1以降で追加されたTheme ruleファイルがUpdate ZIPへ正しく含まれるよう修正し、更新後のruntime整合性を強化しています。あわせてCSP処理を見直し、Theme検証基盤を整理しました。

## 更新内容

- Distribution ZIPとUpdate ZIPへ`docs/theme/theme-rules.json`を確実に収録
- `allow_theme_scripts`を削除し、CSPをfail-closed化
- CoreのTheme rules正本とcanonical SHA-256比較toolを追加
- Theme Specification、ThemeRules、共通Theme validation / package policy、security rule基盤を整理
- Reserved URLの現状を記録する回帰fixtureを追加

Starter ThemeとTheme Developer Centerは、今後のTheme development foundationとしてCore sourceに保持しています。Theme Developer Centerの公式サイトproduction公開は、今回のReleaseには含みません。

v0.6.1からv0.6.2へは、通常の署名付きTomos Updateで更新できます。`config.php`、`content/`、uploads、サイト固有Theme、運用データは更新対象に含まれません。
