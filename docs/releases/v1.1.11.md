# Tomos v1.1.11

## Summary

Tomos Postの管理画面と固定ページの編集導線を整理します。

## Improved

- 原稿作成ツールとして「Tomos Write」「Tomos Workspace」「Obsidianで書く」を同じボタンで案内します。
- 「ページ一覧」に「公開済み記事」と「固定ページ」のタブを用意します。
- トップページ（`index.md`）とAboutページ（`about.md`）を固定ページタブから確認・管理できます。
- 固定ページにも「Tomos Writeで編集」を設置。編集内容をTomos Postへ戻し、確認後に元のページを更新できます。
- 固定ページを公開済み記事タブから除外し、検索・件数・ページ送りの重複を解消します。
- Markdownをダウンロードして再投稿する従来の方法も引き続き利用できます。

## Compatibility / Update

- Tomos Writeの既存の編集連携、記事の更新、画像処理、競合確認は変更しません。
- v1.1.10からv1.1.11への署名付きTomos Updateを準備します。
- 既存の記事・固定ページを初期化せず、`config.php`、`content/`、uploads、サイト固有Theme、cache/storage/trashを保持します。

## リリース状況

正式公開前の候補です。配布範囲、署名付き配布物、実サーバー試験、GitHub Release、公式mirror、最新版catalogの公開確認は未完了です。
