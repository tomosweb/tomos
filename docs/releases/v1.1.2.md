# Tomos v1.1.2

## Summary

Bluesky投稿のハッシュタグとObsidian Publisher連携を含むv1.1.1の改善を引き継ぎ、`social_text`を引用符付きで指定した場合も自然な投稿本文になるようにしました。

## Changes

- `social_text: "Tomosを更新しました。 #Tomos #Obsidian"`のような指定で、外側の引用符をBluesky投稿本文へ含めません。
- 日本語、URL、複数ハッシュタグを含む`social_text`を従来どおり投稿できます。
- `#Tomos`や`#個人サイト`などのBlueskyハッシュタグ、Obsidian本文タグのPublisher連携、PHP 7.4互換性、Bluesky OAuth static backingをv1.1.1から引き継ぎます。

## Compatibility / Update

- v1.1.0からv1.1.2へのBrowser Updateを対象とし、設定、記事、画像、追加Themeなどの運用データを保護します。
- static backingが設定されていない環境では、従来のBluesky OAuth endpointへfallbackします。
