# Tomos v1.0.1

Tomos v1.0.1は、v1.0.0を基準とした小規模な互換更新です。

## Included scope

- 青空文庫式のルビ記法 `｜京都《きょうと》` をMarkdown本文で表示できるようにします。
- インラインコードおよびコードブロック内の同記法は変換しません。
- ルビの親文字・読みはHTMLとして実行されず、安全にエスケープされます。

## Update from v1.0.0

v1.0.0からv1.0.1へ、署名付きTomos Updateで更新します。

`config.php`、`content/`、uploads、カスタムTheme、cache/storage/trashの運用データはUpdateの更新対象に含めません。

本書はTomos v1.0.1のRelease候補案内です。正式Release完了は、既存v1.0.0実環境から実Release artifactを使用したBrowser Update Acceptance GateのPASS後とします。
