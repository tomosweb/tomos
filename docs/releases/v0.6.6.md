# Tomos v0.6.6

Tomos v0.6.6では、Tomos WriteからTomosへ戻る復路handoffを安定させました。

## Fixed

- 既存のPublished一覧windowを再利用した際、Tomos Postのupload画面へ遷移せず、編集済みMarkdownの受信ACKが返らない問題を修正しました。
- 再利用するTomos windowを`/post/?section=upload`へ遷移し、receiverの起動確認後に編集済みMarkdownを渡します。
- v0.6.5のChrome向けポップアップ起動修正を維持しています。

## Security / Compatibility

- 承認、origin/source/session検証、ACK確認、自動公開しない仕様は変更ありません。
- 編集途中の内容はブラウザ内に保持されます。
- 従来の「Markdownを取得」とMarkdown upload更新も継続して利用できます。
- v0.6.5からv0.6.6へ、署名付きTomos Updateで更新できます。`config.php`、`content/`、uploads、サイト固有Theme、運用データはCore Updateの更新対象に含めません。
