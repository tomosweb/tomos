# Tomos v0.6.6

Tomos v0.6.6では、Tomos WriteからTomosへ戻る復路handoffの実障害を修正しました。

## Fixed

- 既存のPublished一覧windowを再利用した際、Tomos Postのupload画面へ遷移せず、編集済みMarkdownの受信ACKが返らない問題を修正しました。
- 再利用するTomos windowを`/post/?section=upload`へ遷移し、receiverの起動確認後に編集済みMarkdownを渡すようにしました。

## Historical correction

- 当時の文書にあった「v0.6.5で修正したChrome向けpopup問題を維持」という説明は撤回します。
- v0.6.5のpopup reservationは、確認済みのv0.6.4 Chrome障害への修正ではなく、未確認のbrowser user-activation仮説に基づく変更でした。
- v0.6.6の復路receiver修正は実際に観測された問題への修正であり、この点は維持します。

## Security / Compatibility

- 承認、origin/source/session検証、ACK確認、自動公開しない仕様は変更ありません。
- 編集途中の内容はブラウザ内に保持されます。
- 従来の「Markdownを取得」とMarkdown upload更新も継続して利用できます。
- v0.6.5からv0.6.6への更新履歴自体は保持します。
