# Tomos v0.5.2

v0.5.2は、Tomos Inboxから公開済み記事を安全に再送・更新するためのメンテナンスリリース候補です。

## 主な変更

- 公開済み記事と同一内容の再送を、エラーにせず重複原稿として整理します。
- 内容が異なる再送は自動上書きせず、既存の競合確認画面から更新または破棄を選べます。
- 更新承認時は再送Markdownの`date`を反映し、既存の`published`を維持します。
- `folder`と保存先pathを含めて既存記事を判定し、別folderの同名ファイルを誤更新しません。

## 更新経路

- v0.5.1からv0.5.2へ、通常のTomos Updateで更新します。Update ZIPの`from_version`は`0.5.1`、`version`は`0.5.2`です。
- v0.4.0からは、v0.5.0、v0.5.1の順に更新したあと、v0.5.2へ更新します。

`config.php`、`content/`、サイト固有Theme、運用データは更新対象に含めません。
