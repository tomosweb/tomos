# Tomos v1.0.5

Tomos v1.0.5は、Tomosの記事をBlueskyへ告知できるSocial Publishingを追加し、Tomos Publisherからの公開結果確認と安全な再送更新に対応する互換更新です。

## Included scope

### Social Publishing / Bluesky

- Frontmatterの `social` / `social_text` 指定に応じて、Tomos記事公開後にBlueskyへ告知できます。
- Tomos記事の公開とBluesky投稿は分離され、Bluesky側の失敗で記事公開をrollbackしません。
- Bluesky OAuth接続、投稿文の自動生成/手動指定、external card、投稿履歴、二重投稿防止に対応します。
- Tomos Publisherは送信ごとの `request_id` で公開結果を取得し、Tomos公開・Bluesky投稿・再投稿防止・下書きをObsidian Noticeへ表示します。
- Publisherから作成した記事は安全な管理記録に基づいて再送更新でき、Publisher管理外の既存記事は自動上書きしません。
- Bluesky連携設定画面をTomos Post共通UIへ統一しました。
- Markdownを `content/` へ直接配置した場合の自動Social Publishingはv1.0.5では対象外です。

### Setup / compatibility

- 初期Setupで選べるThemeを、Tomos本体に同梱する標準Themeだけに限定する既存v1.0.4後続修正を含みます。
- `config.php`、`content/`、uploads、サイト固有Theme、cache/storage/trashの運用データはCore Updateの更新対象に含めません。

## Compatibility

- v1.0.4からv1.0.5へ、署名付きTomos Updateで更新します。
- Tomos Writeとの既存handoff互換を維持します。
- Social Publishing失敗時もTomos記事公開は維持されます。

## Verification

- 公開HTTPS環境でBluesky OAuth接続と実投稿を確認しました。
- Tomos Postで自動/手動投稿文、複数行、文字数超過、external card、二重投稿防止を確認しました。
- Tomos Publisherから新規公開、Bluesky投稿、記事再送更新、Bluesky再投稿防止、下書きを実サーバーで確認しました。
- Bluesky連携設定画面をTomos Post共通UIへ統一し、実画面で確認しました。
- Actions-independent Local Release GateでPHP 7.4 / 8.0 / 8.2 / 8.5、Distribution、Installer Phase 1〜5、署名・checksum検証を実行します。
