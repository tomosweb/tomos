# Tomos v0.5.3

v0.5.3は、Tomos Publisherからの画像付き投稿の受信・復旧を安定化し、PHP 8.5での互換性警告を解消するメンテナンスリリースです。

## 主な変更

### Publisher画像投稿

- Tomos Publisher 0.2.4から送信される画像chunkを非公開stagingで受信し、全画像の受信完了後に既存のInbox / PostUpload / PostPublisherフローへ引き渡します。
- 画像は1記事5点、1点10MBまでとし、chunk、SHA-256、MIME、実画像形式を検証します。
- 自動公開に失敗した画像付き投稿は通常のTomos Post下書きへ変換し、「下書き」から確認・公開・削除できます。
- Publisher由来の未変更な失敗下書きについて、完全な再送時に安全な同名置換を許可します。
- 画像受信、下書き復旧、cleanup、再送、preview、securityの回帰を追加しています。

### PHP 8.5互換性

- PHP 8.5でdeprecatedとなった`imagedestroy()`の呼び出しを見直しました。PHP 7.4以下のresourceでは明示解放を維持し、PHP 8.0以降のGD objectは通常の参照寿命に委ねます。
- PHP 8.5でdeprecatedとなった`curl_close()`をPHP 8.5では呼び出さず、従来環境との互換性を維持します。
- PHP compatibility matrixへPHP 8.5を追加し、PHP 7.4 / 8.0 / 8.2 / 8.5をCI対象としました。
- CIへGDを追加し、`E_ALL`でのImageProcessor互換性回帰を追加しました。

## 更新経路

- v0.5.2からv0.5.3へ、通常の署名付きTomos Updateで更新します。Update ZIPの`from_version`は`0.5.2`、`version`は`0.5.3`です。
- それ以前のバージョンは、従来どおり1バージョンずつ更新してください。
- `config.php`、`content/`、サイト固有Theme、運用データは更新対象に含めません。

## v0.5.2との関係

公開済みv0.5.2のRelease説明にはPHP 8.5互換性改善の記載がありますが、PHP 8.5の`imagedestroy()` / `curl_close()`対応はv0.5.2公開後に開発版へmergeされました。実際の互換性修正を含む最初の正式配布版はv0.5.3です。
