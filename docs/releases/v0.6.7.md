# Tomos v0.6.7

## Historical correction

v0.6.7は、v0.6.6で発生した往路popup regressionへの緊急対応として、PR #179で導入したpopup reservation順序へ戻しました。

ただし、そのPR #179自体が「v0.6.4でChrome popup defectが実際に起きていた」という未確認前提に基づいていました。v0.6.4は導入時にMac Chrome、Mac Safari、iPhone Safariで人間E2EをPASSしており、PR #179前にv0.6.4 Chrome failureの観測記録は確認されていません。

また、v0.6.7のブラウザE2Eは後からtest HTMLがcandidate JSではなく別の旧test assetを読んでいたことが判明し、Acceptanceとして無効でした。

したがって、旧説明の「PR #179の順序へ戻すことで往路を修正した」という評価は撤回します。

## Preserved behavior

- v0.6.6で修正したTomos WriteからTomosへ戻る復路receiverは維持しました。
- 承認、origin/source/session検証、ACK確認、自動公開しない仕様は変更していません。
- v0.6.6からv0.6.7への更新履歴自体は保持します。
