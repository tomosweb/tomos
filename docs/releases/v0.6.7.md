# Tomos v0.6.7

Tomos v0.6.7では、v0.6.6で発生したTomos Write往路popup regressionを修正しました。

## Fixed

- 「Tomos Writeで編集」の承認後にTomos Writeタブが開かないことがある問題を修正しました。
- PR #179で導入した、click user activation中にpopupを予約し、確認ダイアログ後に既存windowをTomos Writeへ遷移する順序へ戻しました。
- v0.6.6で修正したTomos WriteからTomosへ戻る復路receiverは維持しています。

## Security / Compatibility

- 承認、origin/source/session検証、ACK確認、自動公開しない仕様は変更ありません。
- v0.6.6からv0.6.7へ、署名付きTomos Updateで更新できます。`config.php`、`content/`、uploads、サイト固有Theme、運用データはCore Updateの更新対象に含めません。
