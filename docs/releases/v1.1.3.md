# Tomos v1.1.3

## Summary

Bluesky接続開始前にOAuth Metadata/JWKSのstatic backingを自動準備し、既存サイトでは必要な場合だけ安全な`.htaccess` migrationを実行するようにしました。

## Changes

- Bluesky接続開始前にOAuth client keyを確保し、static Metadata/JWKSを生成します。
- `.htaccess`を診断し、safeな場合だけ既存managed blockをstatic-firstへmigrationします。
- static endpoint準備に失敗した場合はOAuth開始前に停止します。

## Compatibility / Update

- `client_id`、`jwks_uri`、`scope`、OAuth protocol、Bluesky posting仕様は変更しません。
- v1.1.2からv1.1.3へのBrowser Updateでは、設定、記事、画像、追加Themeなどの運用データを保護します。
- 既存のPHP endpoint fallbackは削除せず、static backingが利用できない場合も従来URLを維持します。
