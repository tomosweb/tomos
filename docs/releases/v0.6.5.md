# Tomos v0.6.5

## Historical correction

v0.6.5で導入したpopup reservation変更は、v0.6.4で実際に再現・確認されたChrome障害への修正ではありませんでした。

v0.6.4のTomos Write handoffは、導入時にMac Chrome、Mac Safari、iPhone Safariで人間E2EをPASSしていました。v0.6.5変更前に、v0.6.4のChrome popup failureを示すissue、再現手順、console log、実ブラウザ観測記録は確認されていません。

v0.6.5では、一般的なbrowser user-activationの可能性をTomos固有の実障害と誤って扱い、往路を次の形へ変更しました。

`confirm -> window.open(final Write URL)`

から

`window.open(about:blank) -> confirm -> location.href`

この変更は後にproduction往路を壊す系列の起点となりました。

したがって、旧説明の「Chrome環境で発生した不具合を修正した」という因果説明は撤回します。

## Compatibility

- 承認、origin/session検証、自動公開しない仕様は維持されていました。
- 従来の「Markdownを取得」とMarkdown upload更新も継続して利用できます。
- v0.6.4からv0.6.5への更新履歴自体は保持します。
