# Tomos v0.6.5

Tomos v0.6.5では、Tomos Write handoffのポップアップ起動を安定させました。

## Fixed

- 「Tomos Writeで編集」で、Chrome環境により承認後のTomos Write起動がポップアップブロックされる問題を修正しました。
- ポップアップ起動に失敗した場合は、記事本文を送信せず安全に停止します。
- Tomos Writeとのhandoff時の承認・origin/session検証・自動公開しない仕様は変更ありません。

## Compatibility

- v0.6.4で追加したTomos Write編集フローを継続して利用できます。
- 従来の「Markdownを取得」とMarkdown upload更新も継続して利用できます。
- Mac Chrome、Mac Safari、iPhone Safariでhandoffを確認しました。
- v0.6.4からv0.6.5へ、署名付きTomos Updateで更新できます。`config.php`、`content/`、uploads、サイト固有Theme、運用データはCore Updateの更新対象に含まれません。
