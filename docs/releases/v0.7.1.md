# Tomos v0.7.1

Tomos v0.7.1は、Tomos Postを開く前に認証する画面を追加するMaintenance Releaseです。

## Added / Security

- `/post/`を開いたとき、既存のTomos Postを表示する前に認証画面を表示します。
- パスキーまたは管理用合言葉で認証できます。
- 管理用合言葉の30日間の記憶認証を引き続き利用できます。
- 認証後は既存のTomos Postへそのまま移行します。

## Compatibility

- 記事の投稿、下書き、公開済み記事、サイト設定、テーマ、Tomos Updateなど既存のTomos Post機能は変更しません。
- `post/index.php`は既存実装を維持し、認証境界を`post/auth-gate.php`と`post/.htaccess`で追加します。
- Browser Updateで`post/auth-gate.php`と`post/.htaccess`を配布し、root `.htaccess`は更新対象にしません。
- v0.7.0からv0.7.1への署名付きTomos Updateを正式経路とします。
- `config.php`、`content/`、uploads、サイト固有Theme、運用データはCore Updateの更新対象に含めません。

## Release transition

更新元の`VERSION`が`0.7.0`の環境へ、`from_version: 0.7.0`、`version: 0.7.1`のUpdate ZIPを1回適用します。更新後はVERSION、認証画面、パスキー、管理用合言葉、既存Tomos Postへの遷移、保護データ、runtime配置を確認してください。

## Release acceptance

正式公開前に、実際に生成したfull distribution ZIPとUpdate ZIPを展開・適用して、PHP lint、runtime parity、認証壁、パスキー互換、Installer Phase 1〜5、Update rollback、不要ファイル混入なしを確認します。公開Repo、tag、GitHub Release、公式サイト反映は、artifact gate完了後に実施します。
