# Tomos v1.0.2

Tomos v1.0.2は、Tomos Postの検索とTheme管理を改善する小規模な互換更新です。

## Included scope

- Tomos Postの公開済み記事検索で、空白で区切った複数語を使えるようにします。検索語はすべて一致する必要があり、title / filename / path / search textを横断して判定します。
- ユーザーが追加したThemeをTomos Postから削除できます。同梱6Themeは削除できず、使用中Themeは別Themeへ切り替えてから削除します。
- 新しいTheme ZIPを追加した場合、追加完了後にそのThemeを自動で有効化し、生成済みHTMLキャッシュを更新して公開サイトへ反映します。
- 既存Themeを同じTheme IDのZIPで更新する場合は、現在のTheme選択を維持したまま更新後の内容を反映します。
- Theme更新用の一時作業領域が残っている場合に `duplicate_theme` となる問題を修正し、同一versionの再配置を含む既存Theme更新を安定化します。

## Compatibility

- v1.0.1からv1.0.2へ、署名付きTomos Updateで更新します。
- Core Updateでは `config.php`、`content/`、uploads、サイト固有Theme、cache/storage/trashの運用データを更新対象に含めません。
- Theme ZIPの追加・更新・削除はTomos PostのTheme管理から明示的に実行する操作です。
