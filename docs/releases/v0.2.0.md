# Tomos v0.2.0

## 概要

Tomos v0.2.0は、Theme Platform v1をpublic releaseへ導入する新機能世代です。Tomosは0.x開発系列であり、1.0の安定版ではありません。

## 主な変更

- Theme Platform v1のtemplate contextとtheme contractを公開しました。
- ThemeSettingsとtheme-assetsによるサイト固有の表示設定に対応しました。
- structured Home News APIを追加しました。
- Virtual Folder Indexによる一覧表示を追加しました。
- 標準6テーマを1.2.0世代へ整理しました。
- metadataとHTML cacheのfreshnessを改善しました。
- dated filenameからの日付fallbackに対応しました。
- Virtual Folderのfreshness関連処理を改善しました。
- `theme-settings.php` のself-guardを導入しました。
- `.htaccess` はdefense in depthとして維持し、Tomos Updateはroot `.htaccess`を更新しない契約を明確にしました。
- ThemeSettingsへpassword、API key、token、private key等のsecretsを保存しない方針を明記しました。

## Update transition

```text
product: Tomos
from_version: 0.1.0-beta.1
version: 0.2.0
```

0.1.0-beta.1から0.2.0へは、通常のTomos Updateで直接更新できます。中間betaは存在しません。`from_version`は現在の`VERSION`と完全一致する必要があります。

## 保持されるもの

Tomos Updateでは、以下を上書きしません。

- `config.php`
- `content/`
- custom theme ID
- `theme-settings.php`
- `theme-assets/`
- root `.htaccess`
- 運用データ

標準theme ID配下は、通常Updateの更新対象になり得ます。更新前には既存データのバックアップを推奨します。

## version policy

0.2.0はpre-1.0のpublic releaseです。1.0の安定版を意味しません。

- 0.2.0: 新機能世代
- 0.2.1: 0.2系列の修正
- 0.3.0: 次の新機能世代
- 1.0.0: 安定した互換性契約を強く固定する段階
